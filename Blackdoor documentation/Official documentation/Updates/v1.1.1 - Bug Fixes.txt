Blackdoor v1.1.1 - Bug fixes

Bug Fixes:
sqli() no longer crashes on a target with no configured routes - returns a normal result instead.
Object literals, lists, and function calls can now span multiple lines.
ls now shows real permissions/ownership, matching download()/upload().
Web API docs for connect() now carry the same success-vs-login warning the in-editor one has.
In-editor scripting reference now explains what a module's top level can hold.
prompt() no longer discards whitespace-only input.
scp/upload() now correctly lands files inside a destination folder every time.
Settings in someone else's blackdoor.conf now apply fully, same as your own.
theme= in blackdoor.conf now matches a preset regardless of capitalization.
